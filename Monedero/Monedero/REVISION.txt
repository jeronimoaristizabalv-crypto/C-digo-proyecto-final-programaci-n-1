PROYECTO MONEDERO VIRTUAL - VERSION REVISADA

Cambios realizados:
- Se organizó Aplicacion.java en el package principal, siguiendo la estructura del parcial.
- Se renombró viewcontrollers a viewController y se actualizaron imports, module-info.java y referencias FXML.
- Se corrigió la clase principal configurada en el plugin JavaFX de Maven.
- Se ajustó la versión de compilación Maven a Java 17, coherente con la configuración del proyecto de referencia y compatible con JavaFX 21.

  ClienteDuplicadoException, SaldoInsuficienteException y PuntosInsuficientesException.
- Se integraron esas excepciones en las reglas de negocio correspondientes.

- Se evitó contar dos veces una transferencia recibida al calcular el historial para detectar operaciones atípicas.

Verificación:
- Las clases de model y controller compilaron correctamente con javac --release 17.
